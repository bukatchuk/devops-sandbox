# devops-sandbox

Учебная песочница курса подготовки DevOps-инженеров. Здесь проверяются пайплайны:
воркфлоу GitHub Actions запускаются по-настоящему, и числа из прогонов попадают в уроки.

**Материалов курса здесь нет** — только синтетическое демо-приложение и воркфлоу к нему.

## Проверки безопасности

`.github/workflows/security.yml` (gitleaks, Semgrep, osv-scanner, hadolint, ShellCheck, trivy config, zizmor) работает
в режиме отчёта: задания не роняют конвейер. Причина: это учебный стенд, в нём намеренно уязвимый код и зависимости
(`insecure/`) и уроки, которые показывают находки. Результаты — в журналах заданий. Закрепление actions по SHA,
минимальные права и запуск контейнера не от root применены ко всему репозиторию.
