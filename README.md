# devops-sandbox

Учебная песочница курса подготовки DevOps-инженеров. Здесь проверяются пайплайны:
воркфлоу GitHub Actions запускаются по-настоящему, и числа из прогонов попадают в уроки.

**Материалов курса здесь нет** — только синтетическое демо-приложение и воркфлоу к нему.
